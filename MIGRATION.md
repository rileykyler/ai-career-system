# Superseded — see `SYNC.md`

This file briefly described a vault-canonical migration: move the governing documents into this vault, bind the daily scan to this computer, and have it read them from here.

**That plan was reversed the same evening, before anything was repointed.** Binding the scan to this computer would have made a once-daily 9:00am run dependent on the laptop being awake and online, with no second run to cover a miss. The scan has completed six for six while running unbound in the cloud.

The arrangement that replaced it, and the reasoning, is in **`SYNC.md`** at the vault root. Nothing was lost in the switch: every rule change made that evening was already live in the Claude project and stayed there.

This file is kept only so an old link or an old memory doesn't lead somewhere that looks authoritative.
